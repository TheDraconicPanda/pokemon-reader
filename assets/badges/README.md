# HGSS badge artwork

The HeartGold/SoulSilver badge sprites used by Pokémon Reader are sourced from
[Trainer Cards Studio](https://github.com/jonbarrow/trainercards.studio), specifically its
HGSS badge image assets.

Trainer Cards Studio credits the underlying Pokémon assets to their respective
copyright holders. The Pokémon-related artwork remains copyrighted by
Nintendo Co., Ltd., The Pokémon Company, and Game Freak Inc.

These assets are included for the project's personal, non-commercial save-file
reader use and are separate from the project's original source code.
