# Bundled HGSS sprites

505 unmodified Pokémon front sprites (493 species + 12 noncosmetic personal-data
forms), from [PokéAPI/sprites](https://github.com/PokeAPI/sprites/tree/7a7d66b1620e646f69afd48dc1273da9033ede9c/sprites/pokemon/versions/generation-iv/heartgold-soulsilver),
pinned to `7a7d66b1620e646f69afd48dc1273da9033ede9c`.

`manifest.json` records that source path/revision and the SHA-256 of each PNG.
Original Pokémon artwork/game sprites belong to Nintendo, Game Freak and Creatures.
Bundling makes ordinary reference and Reader species imagery independent of live
image requests; this does not establish offline caching for the whole application.
Shiny Reader sprites still load remotely from this same pinned HGSS source.
