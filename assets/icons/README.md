# UI icons

`caught-gen4.svg` is an original, locally hosted 12×12 pixel-style Poké Ball UI
symbol inspired by Generation IV. It is used as a positive Pokédex registration
marker, with accessible alternative text. It is not an extracted Nintendo asset.
See `docs/atlas-caught.md` for behavior, provenance and validation.

`travel/*.svg` are original monochrome UI drawings for Cut, Surf, Strength,
Whirlpool, Waterfall, Rock Climb, Rock Smash, story conditions and path notes.
CSS masks use the active theme colour. They are decorative companions to full
accessible descriptions and the Travel conditions disclosure, not extracted
Nintendo move icons. Dashed borders indicate qualified through/alternative use.
