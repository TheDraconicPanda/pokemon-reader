Save normally in Pokemon, then tap Reader. Emulation pauses. Reader uses the last
completed in-game save; restoring a save state does not refresh it until the next
real in-game save. Use Game, then Resume, to return to play. Automatic Reader copies
are read-only. More -> Export cartridge save exports the active game's raw save.
Reader imports/modified exports remain separate from the active cartridge.

The binary is hosted on GitHub. This Drive file is a download pointer, not an IPA.
Signing/installation, player saves, game compatibility, lifecycle/offload, app-local
persistence and iPhone performance/battery tests remain deferred. melonDS is provisional.
